# Changelog

## 1.2.0

- Click an image or diagram in the preview to open it in a viewer.
- Zoom by pinching, with ⌘+ and ⌘−, or by double-clicking. Drag or scroll to move around.
- Escape or a click beside it closes the viewer.

## 1.1.4

- In Split view, the editor and preview scroll together.
- Double-click a word in the preview to edit it in the source.
- Split view has one scroll bar, and the preview's scroll bar can be dragged.
- Find in Files shows the right line in files with old Mac line endings.

## 1.1.3

- Text that can't be saved is never replaced or dropped.
- Saving keeps a file's encoding instead of converting it to UTF-8.
- LexMD asks before saving over changes another app made.
- Replace from Preview Only shows the source first.
- Update Links no longer breaks links between items moved together.
- Fixes for Git, Copy as Rich Text, shortcuts, Find in Files and preview reloads.

## 1.1.2

- Undoing a paste or a table edit is saved.
- Moving a file with unsaved changes to the Trash offers to keep them.
- Projects in iCloud Drive update when files change outside LexMD.
- Renamed documents stay in Open Quickly's recent files.
- Fixes for code fences, front matter, links with colons and exported HTML.

## 1.1.1

- Fixed a crash when the window was resized or opened narrow.
- Resizing no longer makes the preview blink or lose your place.
- Outline rows can be clicked anywhere along their height.

## 1.1.0

- Diagrams (Mermaid syntax), math, footnotes, and front matter shown as properties.
- Outline panel (⌥⌘O) with headings, backlinks and broken links.
- Wiki links, and suggestions for files, images and headings as you type a link.
- Tabs (⌘T), restored when the project opens again.
- Create, rename, move, duplicate and trash files in the sidebar, with links updated for you.
- Export as PDF or HTML, Print, and Copy as Rich Text.
- Paste or drop images, paste tables from spreadsheets, and Tab between table cells.
- Find and Replace, with whole-word and regular expression options.
- Git: changed files are marked in the sidebar, and Commit… (⌥⌘K) commits the files you pick.
- Focus Mode (⌥⌘F) and Typewriter Scrolling.
- Quick Look previews in Finder, a `lexmd` command, and Shortcuts actions.
- A demo project, built-in Help, and Settings with searchable shortcuts.
- Menus and the toolbar follow macOS conventions, and ⌘W no longer quits the app.
- Better accessibility, and faster with large projects.

## 1.0.0

First public release.

- Project tree that shows only Markdown files.
- Native preview with GitHub-style alerts, task lists, tables and code highlighting.
- Documents never run scripts, and online images load only if you allow them.
- In-place editing with Markdown highlighting, alone or beside the preview.
- Autosave, and reload when files change on disk.
- Find in document, Find in Files and Open Quickly.
- Customizable shortcuts, appearance settings and signed updates.
