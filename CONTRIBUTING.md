# Contributing

Thanks for helping. Open an issue to discuss larger changes before starting.

- Build with `./scripts/build-app.sh`, run `swift test`, and check the result in light and dark appearance.
- Keep the app native: SwiftUI and AppKit, system materials, and no web services.
- Keep files focused and prefer clear names over comments that restate the code.
- Never commit personal paths, private notes, credentials, or signing keys.
